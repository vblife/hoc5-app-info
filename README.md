## Shared devotion preview image

`assets/hoc5-app-icon.png` is an unchanged copy of the mobile app's
`hoc5-ios.png`: a 1024 × 1024 PNG without transparency.

After this change is merged and GitHub Pages finishes publishing, its public URL is:

https://vblife.github.io/hoc5-app-info/assets/hoc5-app-icon.png

See [the website setup guide](hocdevotion-us-share-preview-setup.md) to use it
for devotion link previews. Hosting the image here does not update metadata on
`hocdevotion.us`.
